# Task Manager (Python)

A command-line task manager built to practice core Python concepts — 
started as a basic to-do list and being expanded step by step as I 
learn more. Currently supports adding, viewing, and displaying tasks 
in a numbered list.

## Features
- Add a new task
- View all tasks
- Tasks displayed in a numbered, formatted list
- Complete a particular task

## How to Run
```bash
python task_manager.py
```
